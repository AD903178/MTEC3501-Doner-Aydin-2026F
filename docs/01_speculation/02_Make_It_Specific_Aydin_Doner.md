Working Title

MusiFlip

Project Format

The form of my project is a physical foldable device; an interactive tool of some sort

Project Description

The MusiFlip is an on-to-go, foldable music device that you can use to create and upload music, as well as make your own sounds for other people to use in their music!

User / Integrator Experience

The participant will power up the device, and will be taken to a welcome screen. Once the screen is pressed, the participant will be able to choose whether to upload and/or create sounds, or upload and/or create music. If they choose any of the create options, they will be taken to a page with multiple instruments and tools to create whatever their heart contents. Once finished, they can upload or keep it as a draft to work on it later. However, if they simply choose any of the upload options, they can simply upload via the internal file storage, or through the device.

System Description

The project is a foldable device, similar to a IPhone Duo or Samsung Galaxy Z-Fold 8, and has two dynamic buttons on the sides of the device, a simple power on/off button on the right, and a volume up/down button on the left. The software on this device is very similar to the Samsung Galaxy Z-Fold 8, which has Android 17 and One UI 9. And for charging, a very simple USB C port (a cable will be provided for you).

Explicit Dependency

This project depends on how long the OS will constantly get upgrades for. Most OS doesn’t update forever. As well as the quality of the device being top notch, if our device is horrible quality, nobody will buy it.
